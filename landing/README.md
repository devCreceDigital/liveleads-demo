# Landing de Live Leads

Página de presentación de Live Leads: demo, cómo funciona, waitlist, preguntas frecuentes y contacto.

## Ver la página

Abre `index.html` en el navegador. Las imágenes están en `assets/` y las fuentes se cargan desde Google Fonts.

## Waitlist

El formulario envía los registros a una app web de Google Apps Script que los guarda en un Google Sheet. La URL está en `WAITLIST_ENDPOINT`, dentro del script de `index.html`.
